## Data availability

The Materials Project structures and thermodynamic metadata used for phase retrieval are available from Materials Project subject to its access terms. The DOI-backed literature-route validation set was derived from the public text-mined solid-state synthesis dataset of Kononova et al. after the filtering criteria described in Methods. The processed data generated in this study, including model-evidence benchmark tables, the 120-target route-network benchmark, PET/MP-form comparable reaction tables, DOI-backed literature-route audit tables, route-family similarity scores, recommendation-ablation results, precursor-class diagnostics, confidence-label records, refinement queues, validation summaries, reproducibility manifests and figure-source tables, are available in the InvDesRoute data archive at `ZENODO_DOI_OR_URL`. Materials Project API keys, raw Materials Project database content, full CIF caches and model checkpoints are not redistributed in the archive; users should obtain these resources from their original providers under the applicable access terms.

## Code availability

The InvDesRoute code used for phase retrieval, PET-OAM-XL energy caching, balanced reaction enumeration, MP-form reference construction, practical-route filtering, route scoring, literature-route comparison, diversity-aware ranking, precursor-class diagnostics and gas-reservoir sensitivity analysis is available at `GITHUB_OR_ARCHIVE_URL`. The archived code snapshot corresponding to this manuscript release is available at `CODE_ARCHIVE_DOI_OR_URL`. The repository contains workflow scripts, example formula/CIF inputs, environment specifications, frozen configuration notes, reproducibility manifests and commands for regenerating the benchmark tables, supplementary tables and figure-source data. Materials Project queries require user-provided Materials Project credentials. PET-OAM-XL and other model checkpoints are not redistributed and should be obtained from their original sources.

## 中文参考版本

### 数据可用性

用于相检索的晶体结构和热力学元数据可在遵守 Materials Project 访问条款的前提下从 Materials Project 获取。用于文献路线验证的文本挖掘固相合成记录来自 Kononova 等人的公开数据集及其关联开放仓库。本文生成的处理后数据，包括 120 目标反应网络 benchmark、PET/MP-form 可比反应表、模型对比 benchmark 表、带 DOI 文献路线审计表、路线族相似度分数、推荐排序消融结果、前驱体类别诊断、置信标签记录、精修队列和作图源数据，均可在 `ZENODO_DOI_OR_URL` 获取。数据归档中不包含 Materials Project API key、Materials Project 原始数据库内容或模型 checkpoint。

### 代码可用性

用于相检索、PET-OAM-XL 能量缓存、配平反应枚举、MP-form 参考构建、practical-route 过滤、可合成性评分、文献路线比较、diversity-aware 排序、前驱体类别诊断和气体库敏感性分析的 InvDesRoute 代码可在 `GITHUB_OR_ARCHIVE_URL` 获取。发布版本包含工作流脚本、示例化学式/CIF 输入、环境说明、冻结配置说明，以及再生成 benchmark 表、补充表和作图源数据的命令。Materials Project 查询需要用户自行提供 Materials Project 凭据。PET-OAM-XL 和其他模型 checkpoint 不随本包分发，应从原始来源获取。
