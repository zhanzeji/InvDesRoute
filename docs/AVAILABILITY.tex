\section*{Data availability}
Materials Project structures and thermodynamic metadata are available subject to its access terms~\cite{jain2013commentary}. Literature records were derived from the public Kononova and Lee datasets~\cite{kononova2019text,cedergrouphub_textmined_synthesis_public,lee2025text}. Processed benchmark summaries and archived validation flags are provided in the versioned data archive at \url{https://doi.org/10.5281/zenodo.24453293}. Full benchmark recomputation requires the original inputs. NIST-JANAF reference tables can be obtained from the original database (DOI: 10.18434/T42S31).

\section*{Code availability}
The InvDesRoute source and scripts for the documented reproducibility analyses are available at \url{https://github.com/zhanzeji/InvDesRoute}, with the corresponding software release archived at \url{https://doi.org/10.5281/zenodo.24453272}. Model identifiers and checkpoint checksums are provided; model weights are obtained separately under their original terms.
