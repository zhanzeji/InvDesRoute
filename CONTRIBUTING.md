# Contributing

Keep scientific changes separate from formatting changes. New benchmarks must name their input cohort, energy convention, units, exclusions and reference source. Changes to score weights, thresholds or candidate budgets require development-only selection and a new independently evaluated version. Do not overwrite frozen input records to make a check pass. Report negative results and missing references explicitly.

For a pull request, describe the concrete behavior changed and the validation performed. Do not include credentials or raw licensed model files. Dataset corrections should retain the original source record and a machine-readable correction/provenance record.
