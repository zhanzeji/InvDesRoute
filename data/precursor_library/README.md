# Precursor library summaries

This supplement contains a summary of the 906 unique formulas generated by the archived rules and a coverage table for 390 cohort-target instances. The candidate rules depend on the target composition. Scoring and matching classes are workflow labels.

| File | Contents |
| --- | --- |
| generated_formula_summary.csv | Generated formulas, classification labels, cohort membership and counts |
| cohort_target_coverage.csv | Counts of rule candidates and archived phase-pool coverage by cohort and target |
| SHA256SUMS.json | SHA-256 digests for the two tables and this index |

The author-generated summaries are available under CC BY 4.0. The rules are documented in the MIT-licensed source under code/workflow. Materials Project identifiers, cached energies and row-level phase-pool inputs are outside the scope of these summaries. Literature augmentation status is recorded as described in the coverage table. For upstream data references, see [Data sources](../../docs/DATA_SOURCES.md).
